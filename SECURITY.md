# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities through **GitHub's private vulnerability reporting** (Security Advisories) in this repository, at:

**https://github.com/hobbs136/dbmaster/security/advisories** (Security → Report a vulnerability)

Please do **not** report security issues through public GitHub Issues, discussions, or pull requests.

When reporting, include:

- A description of the vulnerability and its impact
- The affected version, tag, or commit
- Step-by-step instructions or a proof of concept to reproduce it
- A suggested fix, if you have one (optional)

## Scope

This policy covers **this repository only** — the DbMaster Flutter desktop client. Vulnerabilities in the companion automation engine should be reported in the [dbmaster-server repository](https://github.com/hobbs136/dbmaster-server).

## Disclosure

Please keep vulnerability details private until a fix has been released. Reports are handled privately: we will investigate and publish a patched release before any public disclosure. Reporters who wish to be credited will be named in the release notes unless they prefer to remain anonymous.

There is currently no bug bounty program.
