# Title 栏菜单 UX 分析

> 对比基准：DBeaver、TablePlus、DataGrip、VS Code、Figma
> 分析日期：2026-06-10

---

## 一、当前布局

```
┌─ Logo ────────────────────────────────┬── 右侧按钮组 ───────────────────┐
│ 🗄️ DbMaster                           │ ⊕ 🏢 🔗 │ 🔍 ✨ 🌙 ⚙️ │
│                                        │ 新  管  断 │ 命  AI 主题 设 │
│                                        │ 连  理  连 │ 令           置 │
│                                        │ 接  连  接 │ 面            │
│                                        │     接     │ 板            │
└────────────────────────────────────────┴───────────────────────────────┘
```

- 高度：`headerHeight` (44px)
- 左侧：纯文字 Logo（无图标动画、无版本号、无 Pro 标识）
- 右侧：8 个图标按钮，仅 `/` 按钮标注了快捷键提示
- 断开连接是条件渲染（`SizedBox.shrink()` when not connected），导致按钮数量动态变化
- 一条竖线分割 Command Palette 和前面的连接管理按钮

---

## 二、存在问题

### 🔴 P0 — 影响使用

#### 1. 按钮无明确分组，认知负载高

| 工具 | 分组方式 |
|------|----------|
| VS Code | 左侧导航 / 中央编辑器标签 / 右侧操作 (明确三区) |
| DataGrip | 文件操作 | 运行配置 | 工具 | VCS |
| DBeaver | 文件 | 编辑 | 导航 | 帮助 |
| **DbMaster** | **8 个扁平按钮排成一行，无语义分组** |

当前只有一条竖线把"命令面板 / AI / 主题 / 设置"与前面的"连接管理"隔开。但"命令面板"和"连接管理"同属"导航/发现"类，"AI"是独立功能，混在一起不合理。

#### 2. 断开连接按钮条件渲染破坏布局

已连接时出现红色 `link_off`，未连接时消失。右侧按钮组从 8 个变 7 个，按钮间距变化——用户每次连接/断开都要重新定位眼睛找按钮。

#### 3. 竖线位置语义不对

```
[连接管理按钮] [│] [命令面板] [AI] [主题] [设置]
                 ↑ 为什么把连接管理和命令面板隔开？
                   它们同属"发现/导航"
```

VS Code / DataGrip 的分隔线用于分离**不同功能区**，这里反而把同类功能隔开了。

### 🟡 P1 — 影响效率

#### 4. 无 Pro 版本标识

购买系统已经实现（PurchaseProvider），但 Title 栏零展示。免费版用户不知道自己随时可以升级。

**对比**：
- TablePlus：Title 栏显示 `TablePlus (Free)` 或 `TablePlus Pro`
- Figma：左上角升级按钮
- VS Code：无（开源免费）

#### 5. 快捷键只展示了 `/`

所有按钮中只有命令面板标注了 `(/)` shortcutHint。执行查询 `⌘Enter`、格式化 `⌘⇧F`、新建连接 `⌘⇧N` 等都没有提示——用户只能靠记忆或 tooltip 悬停发现。

#### 6. 菜单无分类弹出——全在 HomeScreen 单层处理

所有对话框（连接、设置、ER图、性能分析、审计日志、命令面板等）的弹出逻辑全部堆在 `_HomeScreenState` 中。Header 只是"按钮+回调"，没有任何菜单聚合能力：

| 工具 | 菜单架构 |
|------|----------|
| DataGrip | File / Edit / View / Navigate / … 标准菜单栏 |
| DBeaver | 同样的标准菜单栏 + 工具栏 |
| **DbMaster** | **8 个独立按钮 → 各自弹出对话框** |

没有"View"菜单（切换侧边栏/主题/字号）、没有"Help"菜单（关于/文档/反馈）。

### 🟢 P2 — 视觉打磨

#### 7. Logo 区域单调

当前只是 `🗄️ DbMaster` 文字。Figma/Linear 在 Logo 后显示工作区名称或项目名，DataGrip 在 Title 显示项目名。DbMaster 没有利用这个空间。

#### 8. 主题切换按钮无状态指示

日/夜切换只是一个图标，没有文字标签说明当前模式。用户第一次使用可能不知道这个图标是干嘛的。

#### 9. 工具栏溢出无处理

8 个按钮在小窗口（~900px 宽）下可能溢出 Title 栏。当前没有 `SingleChildScrollView` 或溢出菜单。

## 三、建议方案

### 方案 A：轻量重组（30 分钟）

```
┌─ Logo ───────────┬── 连接 ──┬── 发现/工具 ────┬── AI ──┬── 设置 ──┐
│ 🗄️ DbMaster      │ ⊕ 🏢 🔗 │ 🔍              │ ✨     │ 🌙 ⚙️    │
│                   │          │  (Ctrl+/)       │        │           │
└───────────────────┴──────────┴─────────────────┴────────┴──────────┘
```

**改动：**
1. 重新分组：连接管理 | 命令面板 | AI | 主题+设置（4 个语义组）
2. 断开连接按钮改为常驻（灰色 disabled 代替消失），布局稳定
3. 每组间用 `SizedBox(width: 4)` 微间距 + `SizedBox(width: 12)` 大间距

### 方案 B：添加功能菜单栏（2-3 天）

完全对标 DataGrip，实现标准 `MenuBar`：

```
File         Edit       View         Navigate      Tools        Help
─────────    ───────    ──────       ────────      ──────       ─────
New Conn     Undo       Sidebar      Cmd Palette   ER Diagram   About
Open...      Redo       AI Panel     Quick Search  Schema Diff  Docs
Save Query   Cut        Theme →      Go to Table   Smart Import Shortcuts
Quit         Copy       Zoom →       ...           ...          ...
             Paste      ...
```

**优势**：满足桌面 App 用户的肌肉记忆，释放 Header 空间。
**代价**：Flutter 桌面 `MenuBar` 在 macOS 上有已知的 rendering issues。

|---|------|------|:---:|
| 1 | 按钮重新分组 | 连接 | 发现 | AI | 设置 | ~15 |

| 3 | 取消中间竖线，正确分组 | `SizedBox` 组间间距 | ~5 |
