DbMaster 组件与交互细节

关键组件状态 + 微交互规范

状态可见

每个可交互元素都有 default / hover / active / selected / disabled 的明确视觉反馈，避免用户猜测当前状态。

反馈有度

成功轻反馈、失败重反馈、加载有进度但不过度打扰，让状态信息层次分明。

减少跳变

用过渡动画替代突然出现，保持空间锚点，防止布局抖动打断用户心流。
